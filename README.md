# Castbeam releases

Installers for **Castbeam**, the service control desk for hybrid church services.

Download the latest version from **[Releases](https://github.com/armie3/castbeam-releases/releases/latest)**:

- **Mac (Apple Silicon):** `Castbeam-x.y.z-arm64.dmg`
- **Mac (Intel):** `Castbeam-x.y.z.dmg`
- **Windows:** `Castbeam-Setup-x.y.z.exe`

Castbeam checks this page for updates and tells you when a new version is ready.

The first time you open an unsigned build: on Mac, right-click the app → **Open**; on Windows, **More info → Run anyway**.

This repository only holds installers; Castbeam's source code is private.
